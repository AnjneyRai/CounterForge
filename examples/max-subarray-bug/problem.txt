Problem: Maximum Non-Empty Subarray Sum

Description:
Given an array of n integers, find the maximum sum of elements in a contiguous,
non-empty subarray. A subarray is a contiguous segment of the array.

Input Format:
- The first line contains a single integer n (1 <= n <= 100,000) — the number of elements.
- The second line contains n space-separated integers a_1, a_2, ..., a_n (-10^9 <= a_i <= 10^9).

Output Format:
- Output a single integer representing the maximum possible sum of a contiguous non-empty subarray.

Sample 1:
Input:
5
-1 2 4 -3 5

Output:
8

Explanation:
The contiguous subarray [2, 4, -3, 5] yields the maximum sum: 2 + 4 + (-3) + 5 = 8.

Note on Constraints:
The subarray must be NON-EMPTY (contains at least one element).
If all numbers are negative, the answer should be the largest negative number (the least negative value).
